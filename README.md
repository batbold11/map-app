# Хаягийн интерактив газрын зураг (Excel/CSV → Map)

## Архитектур

```
map-app/
├── index.php              # Үндсэн хуудас (upload + хайлт + газрын зураг)
├── api/
│   └── geocode.php        # PHP backend: хаяг → солбицол (Nominatim), файл кэштэй
├── assets/
│   ├── css/style.css
│   └── js/app.js          # Excel/CSV парс (SheetJS), Leaflet маркер, хайлт/zoom
├── cache/
│   └── geocode_cache.json # Geocoding кэш (автоматаар үүснэ)
└── sample-data.csv        # Туршилтын жишээ файл
```

- **Frontend**: Bootstrap 5 + Leaflet.js (OpenStreetMap, үнэгүй, API key шаардлагагүй)
- **Excel/CSV Parser**: SheetJS (xlsx), клиент талд (браузер дээр) шууд хөрвүүлдэг
- **Backend**: Цэвэр PHP (composer/сан шаардахгүй), Nominatim geocoding API руу дуудалт хийж, файл кэшлэдэг

## XAMPP дээр ажиллуулах (MySQL-тэй)

1. `map-app` фолдерийг `C:\xampp\htdocs\` дотор хуулна.
2. XAMPP Control Panel-с **Apache** болон **MySQL** хоёуланг нь эхлүүлнэ.
3. `http://localhost/phpmyadmin` руу орж, `schema.sql` файлыг **Import** хийнэ (эсвэл шинэ DB үүсгээд SQL-г тэнд paste хийж Go дарна). Энэ нь `map_app` нэртэй DB, `people` хүснэгт, жишээ 3 мөр өгөгдөл үүсгэнэ.
4. Хэрэв MySQL root хэрэглэгч дээрээ нууц үг тохируулсан бол `config/db.php` доторх `$DB_PASS`-г шинэчилнэ.
5. Браузераар нээнэ: `http://localhost/map-app/` — хуудас нээгдмэгц **автоматаар MySQL-с** өгөгдлийг уншиж, geocode хийгээд газрын зурагт харуулна (эхний удаа geocoding хийгдэх тул хэдэн секунд шаардаж болно; дараагийн ачааллаас DB дотроо хадгалсан солбицлыг шууд ашиглана).
6. Шинэ хүн нэмэх/засах/устгах бол **"Өгөгдөл удирдах"** товч дарж `admin.php` руу орно — Excel хэрэггүйгээр шууд формоор бөглөж болно.

### Excel/CSV upload одоо ч ажиллана
Зүүн панелийн "Эсвэл Excel/CSV файл оруулах" хэсэг хуучин шигээ бие даан ажиллана — энэ нь MySQL-г тойрч, файлаас шууд газрын зурагт харуулах (DB-д хадгалахгүй, түр зуурын харагдац).

## Excel/CSV баганын шаардлага

Эхний мөр (header) дараах нэрсийн аль нэгийг агуулсан байх ёстой (том/жижиг үсэг ялгаагүй):

| Багана | Хүлээн зөвшөөрөгдөх нэрс |
|---|---|
| Нэр | `Нэр`, `Name` |
| Байгууллага 1 | `uilchilgeeni baiguulga1`, `Байгууллага1`, `org1` |
| Байгууллага 2 | `uilchilgeeni baiguulga2`, `Байгууллага2`, `org2` |
| Утас (заавал биш) | `Утас`, `Phone` |

## Geocoding тухай анхаарах зүйлс

- `api/geocode.php` нь **Nominatim (OpenStreetMap)**-ийн үнэгүй geocoding API ашигладаг. Тэдний бодлогоор **секундэд 1 хүсэлт**-ээс хэтрэхгүй байх ёстой тул серверт `usleep(1.1s)` тавьсан — том файл (жишээ нь 100 мөр = 200 хаяг хүртэл) upload хийвэл хэдэн минут зарцуулж болно.
- Хаяг бүрийг **нэг удаа л** geocode хийж, `cache/geocode_cache.json` дотор хадгална — дараагийн удаа адилхан хаяг дахин орж ирвэл шууд кэшээс уншина.
- Хэрэв хаяг тодорхойгүй, эсвэл олдохгүй бол markers дээр гарахгүй, харин зүүн талын "Тэмдэглэгээ" хэсэгт **улаан анхааруулга** хэлбэрээр жагсаагдана.
- 300-с олон мөртэй файл нэг дор явуулбал алдаа өгнө (Nominatim rate-limit-ээс хамгаалах зорилготой) — файлаа хэсэгчлэн upload хийнэ үү, эсвэл хурдны хязгаарлалттай Google Maps/Mapbox geocoding руу шилжинэ.
- Илүү найдвартай/хурдан geocoding хэрэгтэй бол (жишээ нь мянга гаруй хаяг) Google Geocoding API эсвэл Mapbox geocoding API руу шилжихийг зөвлөж байна (`api/geocode.php` доторх `geocodeAddress()` функцийг л сольж бичихэд хангалттай).

## Онцлогууд

- Excel/CSV upload → автоматаар geocode хийгээд газрын зураг дээр pin тавина
- Байгууллага1 = ногоон, Байгууллага2 = цэнхэр маркер, popup дээр нэр/хаяг/утас харагдана
- Нэрээр бичихэд шууд autocomplete жагсаалт гарч, сонговол тухайн хүний бүх маркер руу zoom хийнэ
- Responsive: гар утас дээр газрын зураг дээрээ, доор нь upload/хайлтын card-ууд байрлана

## Цаашид сайжруулж болох зүйлс

- Geocode хүсэлтийг background job (queue) руу гаргаж, upload хийсний дараа progress bar-аар илүү нарийн явц харуулах
- Латин → Cyrillic хөрвүүлэлт (`latinToCyrillicApprox`) 100% нарийвчлалтай биш (х/kh, у/ү зэрэг олон Латин үсэг хэд хэдэн Cyrillic үсэгт харгалздаг тул алдаатай тохиолдол гарч болно) — маш нарийн хаяг шаардлагатай бол Cyrillic-ээр шууд бичих нь илүү найдвартай

## Хайлт болон хаяг оруулах: Cyrillic + Латин хоёуланг дэмждэг

- **Нэрээр хайх** (`searchInput`): "Батболд" эсвэл "Batbold" аль ч хэлбэрээр бичсэн ижил хүнийг олно (`assets/js/app.js`-ийн `normalizeForSearch` функц).
- **Байгууллага1/2 хаяг** (Excel багана эсвэл admin.php форм): Латин үсгээр бичсэн хаягийг (`api/geocode_helper.php`-ийн `latinToCyrillicApprox`) автоматаар Cyrillic рүү ойролцоогоор хөрвүүлж, хоёр хувилбараар (Латин болон Cyrillic) geocode хийж үзнэ — аль нь эхлээд олдоно, түүнийг ашиглана.

## Marker cluster

Маркер олон бүртгэгдвэл ойролцоо байрлалынхыг автоматаар груплэж, тоогоор нь бөмбөлөг хэлбэрээр харуулна (`Leaflet.markercluster`) — дарахад задарч, дотор нь орсон маркеруудыг харуулна. Нэрээр хайж тухайн хүн рүү шилжихэд ч клaster-аас автоматаар "задардаг" (`zoomToShowLayer`).
